# MedSync — web app (Next.js)

This is the frontend of MedSync. Local development, environment variables and Vercel
deployment are documented in the repository's [SETUP.md](../SETUP.md); the code layout is
in [CODEBASE_INDEX.md](../CODEBASE_INDEX.md).

```bash
cp .env.example .env.local   # fill in your Supabase URL/anon key and backend URL
npm install
npm run dev                  # http://localhost:3000
```
